# 翰林四上 CH2｜家鄉探究所

李采蓉老師的四年級社會自主學習網站。主題為「家鄉的地形與氣候」。

## 學習內容

- 先備基地、五大地形辨識與地形線索探究。
- 氣候比較、生活物產與證據判讀。
- 每課三個挑戰與一個生活情境。
- 十五題單元測驗、逐題解析、最高分保存。
- 兩課完成且測驗達八十分後，可產生個人 PDF 證書。

## 隱私

免登入，進度只保存在學生自己的瀏覽器，最近儲存後三百六十五天到期；不集中收集姓名與作答。證書可使用暱稱。沒有正式成績驗證或集中教師後台。

## 教材與素材

依使用者提供之翰林四上第二單元教材改寫；不包含課本 PDF 或原書插圖。本站地形與氣候示意圖為重新繪製。課本氣候資料期間為 1991～2020 年，不是即時天氣預報。

## 部署

純靜態網站，無需安裝依賴或建置。將 GitHub Pages 來源設為 main 分支根目錄（/）。

## 驗證範圍

程式語法、課程規格、計分與完成資格邏輯檢查通過。瀏覽器視覺、手機操作與 PDF 下載尚待實機驗證。
